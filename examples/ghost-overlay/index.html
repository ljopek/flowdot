Flowdot — ghost / counterfactual overlay

A ghost "caption" x,y line declares a counterfactual annotation — the cost of the naïve alternative. Ghosts are a toggleable layer, hidden by default; the library auto-renders a Ghost: off/on button that shows/hides them. Click it — the dim, dashed "what a naïve impl would cost" notes fade in over the real diagram. No host JS.
