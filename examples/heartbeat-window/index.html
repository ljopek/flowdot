Flowdot — heartbeat & window

now() is the runtime clock — time as a value. Data arrivals stamp set lastSeen = now(); a heartbeat rides its own track every 1s; and a window boundary fires only after a silent window (when now() - lastSeen >= 1.2), re-arming each time. No host timer, no JS.
