Flowdot examples

Click any example -- it opens in the pane on the right. Every example is no JavaScript and shows its .flow source below the diagram.

Structure

hello-world
The smallest diagram — a node, an edge, a flow. One source → one worker.
annotations
Add notes to nodes and a legend for diagram colours.
edge-labels
Label and style connections to distinguish protocols and error paths.
packaged-bundle
The consumer path: one <script src> loads the built dist/flowdot.js bundle, not the four src/*.js files. Vendor it; never point at node_modules.
zones
Labelled grouping bands that infer their box from the lanes they span.
comprehensions
set, each … in, and {expr} — a 3×3 grid from six lines.
owned-shards
A pinned core with idle (lit-but-idle: owns its data, at rest) and owns:"P0" (ownership caption) — a shard panel with no page-JS custom kind.
free-divider
divider "label" x1,y1 -> x2,y2 (alias rule) draws a standalone labelled line — a process boundary or a hot/cold split — that no note or zone could express. Dashed by default; add solid and a #colour.

Layout

auto-layout
Place nodes by lane × rail — no coordinates. Zero-JS auto-boot.
routing
Route packets by ordered content guards, with a clear default branch.
ortho-routing
Opt-in route:ortho on an edge/road — right-angle (elbow) wires that bend through the midpoint instead of cutting diagonally across a packed layout. Straight (bezier) stays default.

playground

Behaviour

flow-pick
A weighted | pick — each packet takes one branch (80/20, seeded).
flow-fanout
A & fan-out — a copy of every packet to every subscriber.
flow-actions
Hop { count …; push … } actions mutate the runtime state store.
flow-schedule
spawn a secondary packet and after D: schedule an event.
flow-events
drop if rand()<0.2 and an on <event> handler.
flow-branch
Combine weighted choice and fanout to show alternate and shared paths.
join
Show converging paths at a shared destination.
request-retry
Illustrate request, response, loss and retry paths.
message-queue-backpressure
Combine bounded queue occupancy, producer bursts and dropped packets.
pubsub-tiered
Combine publisher fanout, latest-value slots and independent reader rates.
periodics
Tiered every … per … when drainers, each on its own timer.
matrix-decay
A matrix with decay:<rate> — a cell lit by write m.i.j fades back to idle on its own, no host JS.
ring-inline
A ring sits ON the flow path (a ~> ring ~> b) via its out port — a packet routes through it; push/drain raise and lower the fill.
pipeline-stages
~> pipe.stages routes a packet THROUGH a pipeline's stages — the dot walks decode→canonicalise→offer, one sub-leg per stage.
packet-payload
pick i in [...] binds a per-fire value; write grid.{i}.0 lights one cell per tick (not the whole column). Seeded + decaying.
component-verbs
Hop actions call component methods: highlight m.row:i, down/up m.col:j, surge ring. A reader picks a row, writes it, and highlights it.
tiered-delivery
A #token on a spawn colours the spawned packet, so every … : spawn … #seriesN delivers each tier's dot in its own colour.
conflating-fanout
A slot node is one last-value buffer per subscriber — it flashes superseded when a new value overwrites an un-read one. N slots draw a legible conflating fan-out.
live-readouts
A readout name:blended node binds to a store counter and renders it as a live number that ticks as the flow runs — the telemetry layer, zero JS.
outcome-demux
A packet's fate drives its colour: a pick value + a guarded | demux with a #colour per branch — emitted (emerald), stale (amber), suppressed (rose), each recolouring the packet and flashing its own node.
heartbeat-window
now() is the runtime clock: a heartbeat rides its own track with a distinct token, and a window-boundary emission fires only after a silent window (when now() - lastSeen >= W, re-arming) — time-as-event, no host timer.
snapshot-burst
snapshot grid bulk-reads (visibly pulls) the whole grid at once (a late-join snapshot); snapshot grid.row:i pulls one whole row (a shard read). A burst ring sweeps the pulled cells and re-freshens them.

Controls

transport-controls
One controls line auto-renders a play/pause · reset · speed bar (zero-JS).
modes
A storm mode toggle — sources fire faster while active.
mode-drives-state
A mode drives state, not just rate: storm takes a matrix column down, floods a ring lane (surge), and speeds a matrix's decay — applied on enter, reverted on exit.
narration
A narrate timeline cycles a guided story on the runtime clock — each narrate <dwell> <node…> : "caption" step spotlights the node(s) with a pulsing ring and shows a caption banner. Zero JS.
ghost-overlay
A ghost "caption" x,y [-> x2,y2] line declares a counterfactual annotation — the naïve alternative's cost (GC debt, pointer-chase, blocking queue). Ghosts form a toggleable layer, hidden by default; the library auto-renders a Ghost: off/on button that shows/hides it. Zero JS.

Theming

palette-colors
Colour tokens (#sky) + the theme ramp by index (#series0) that map per theme.
branded
A registered theme pack (diagram … light) re-skins the whole diagram. Ships dark/light; register your own.
recolor
Set colours for component kinds with one diagram-level declaration.
swatches
Browse the built-in theme colours and semantic colour roles.
theme-light
See how theme colours adapt in the light colour scheme.
