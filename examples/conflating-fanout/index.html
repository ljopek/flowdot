Flowdot — conflating fan-out

a slot is one last-value buffer per subscriber. The publisher writes the newest value into every slot; each reader cleans its own at its own rate. A slot flashes "superseded" when a new value overwrites one the reader hasn't taken yet — so the slow readers conflate while the fast one keeps up. No host JS.
