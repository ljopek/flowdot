# Contributing

Thanks for your interest in Flowdot!

## Development

- Zero runtime dependencies; Node ≥ 18.
- `npm test` runs the unit suite (`node --test`).
- `npm run build` produces the `dist/` bundles (UMD + ESM).

## Pull requests

1. Fork and create a branch.
2. Add or update tests for your change; keep `npm test` green.
3. Keep diffs focused and match the surrounding style.
4. Open a PR with a clear description of the change and why.

## Reporting issues

Please include the `.flow` source (or a minimal reduction), what you expected, and what you saw —
a copy of any located error message is especially helpful.
